## ⚠️ 先讀這段：目前的研究結論

**這套系統目前處於研究階段，不建議實盤。**

2026-11 修正回測方式後，在研究期（2014 年底到 2023 年底、全台股約 1030 檔）的結果：

| 設定 | 訊號平均 R | 組合總報酬 |
|---|---|---|
| 原始回測（用訊號當天收盤價成交、漲停也買得到） | 0.91 | +263% |
| **實盤真實模式**（實盤真的做得到的成交方式） | **1.06** | **−20%** |
| 隨機進場對照組（同樣出場規則，進場日隨機） | 1.16 | +112%（10 組平均） |

這代表三件事：

1. 舊版回測績效大部分來自**實盤做不到的成交假設**。
2. **FVG 進場訊號沒有贏過隨機進場。**真正有效的是出場規則（小停損、讓利潤奔跑）加上台股這幾年的多頭。
3. 下一步要研究的是**進場方式**，詳見[第十節](#十目前研究進度)。

詳細數字在 `research_results/` 資料夾。

## 一、這套系統在做什麼

這是一個台股的量化交易系統，原始設計邏輯是：

1. **在選定的產業裡找出 FVG（Fair Value Gap）突破訊號的股票**
2. **用 0050 判斷大盤環境，只在允許的環境進場**
3. **進場後讓利潤奔跑，靠少數大波段賺錢**

它的性格：**勝率只有約 15–25%，大部分交易小虧，靠少數幾筆大波段把整體拉成正報酬。**

### 實際的交易規則（程式碼裡真正在做的事）

| 項目 | 規則 |
|---|---|
| 訊號 | 三根 K 線：第 3 根最低價 > 第 1 根最高價（缺口 ≥ 門檻），第 2 根是紅K，收盤在季線上，開盤跳空不超過 5% |
| 停損距離 | max(缺口大小, 收盤價 × 3%)。實務上幾乎都是 **3%** |
| 移動停利 | 最高價 − 停損距離 × 倍數。倍數 10 ≈ **從最高點回落 30% 才出場** |
| 市場環境 | 0050 vs 200 日均線（Bull / Bear）＋ 20 日年化波動率 25%（HighVol / LowVol） |

> 注意：雖然名稱叫 SMC，但它是在缺口形成當天**追價進場**，不是等回測缺口才進場。本質上比較接近「動能突破策略」。

## 二、第一次安裝（只做一次）

### 步驟 1：安裝 Python 套件

```bash
pip install -r requirements.txt
```

### 步驟 2：設定環境變數（Telegram 通知用，可略過）

**不要把金鑰寫在程式碼裡。**

```bash
export TELEGRAM_BOT_TOKEN="你的token"
export TELEGRAM_CHAT_ID="你的chat_id"
```

Windows 用「系統 → 環境變數」設定，或在 PowerShell 用 `$env:TELEGRAM_BOT_TOKEN="..."`。
沒設定也能用，只是不會發 Telegram 通知。

- **Telegram token：**在 Telegram 找 @BotFather 建立機器人取得。
- **chat_id：**找 @userinfobot 取得。

### 步驟 3：產生股票清單

```bash
python get_data.py
```

會從證交所抓上市公司清單，產生 `stock_list.csv`（欄位：`category,ticker,name`）。

### 步驟 4：下載歷史 K 線（第一次最久）

```bash
python update_data.py
```

約 1000 多檔，需要 30–60 分鐘。資料存在 `local_data/`（例如 `local_data/2330.parquet`）。
沒有先下載也可以用，系統會在需要時自動從 yfinance 抓，只是比較慢。

### 步驟 5：啟動系統

```bash
streamlit run app.py
```

瀏覽器會自動開啟 `http://localhost:8501`，看到五個分頁就成功了。

## 三、五個分頁各做什麼

| 分頁 | 用途 |
|------|------|
| **1. 即時掃描雷達** | 依今天的訊號列出可進場股票、建議股數，並發 Telegram |

## 四、參數說明

舊版手冊的「最佳參數」是用舊的回測方式選出來的，**現在不建議直接當成定案**。以下只是目前的預設值：

| 參數 | 預設值 | 說明 |
|------|-----|------|
| 最小缺口 (gap) | 0.3% | FVG 缺口門檻 |
| 出場方式 | 移動停利，倍數 10 | ≈ 從最高點回落 30% 出場 |
| 單筆風險 | 0.5%（實盤雷達）/ 2%（回測預設） | 每筆最多虧帳戶幾 %。回測和實盤請設成同一個值 |
| 允許進場環境 | Bull_LowVol + Bear_HighVol | ⚠️ 這個組合是看歷史結果挑的，有過度擬合疑慮 |
| 最大持倉數 | 5 | 同時最多持有幾檔 |
| 單一產業上限 | 2 | 同產業最多幾檔 |

**關於舊版的「報酬率 1600%、最大回撤 22%」：**那是全期間、原始回測方式算出來的。它用訊號當天收盤價成交、漲停也買得到、只用已實現損益算回撤，而且股票清單沒有已下市公司。這個數字**不代表實盤能做到的績效**。

## 五、回測真實度：原始回測 vs 實盤真實模式

在 Tab 3 的「研究設定」勾選「實盤真實模式」，回測會改成模擬實盤真的做得到的事：

| 項目 | 原始回測 | 實盤真實模式 |
|---|---|---|
| 進場 | 訊號當天收盤價 | 隔天掛觸價單（觸價 = 訊號日收盤），有觸發才成交，成交價 = max(開盤, 觸價) |
| 漲停 | 照樣買到 | 一字漲停買不到 |
| 跌停 | 照樣賣掉 | 一字跌停賣不掉，留到隔天 |
| 前 10 天 | 1R 停損 | 只有 2R 緊急停損（天數可調，0 = 關閉） |
| 同一檔 | 可重複開倉 | 已有部位就略過新訊號 |
| 移動停利 | 同根 K 棒先上調再判斷 | 先判斷出場，收盤後才更新 |
| 資料結束時的未平倉部位 | 直接消失 | 以最後收盤價結算 |
| 單筆資金上限 | 無 | 預設 20% 淨值 |

不勾選時，結果和舊版完全相同。**研究時請一律用實盤真實模式。**

## 六、研究紀律（調參數之前必讀）

### 考試期（Holdout）

`config.py` 的 `HOLDOUT_START`（預設 2024-01-01）之後的資料保留當「最後考試」。

- Tab 3 預設只用**研究期**（之前的資料）
- 所有參數調整都只看研究期
- 全部定案後，才切到「考試期」驗證**一次**。看過考試結果再改參數，這段資料就失效了

### 隨機進場對照組

訊號數量不變，但進場日期隨機打散，出場規則完全不變。
**任何進場方式都要先贏過隨機對照組，才算真的有優勢。**

### 一次只改一個東西

每次只改一項規則，跟基準比較，只保留真的有改善的。並且記錄每一組試過的參數。

### 看訊號層，不要只看組合報酬

同樣是隨機進場，換一組亂數，組合報酬就從 +6% 跳到 +266%。單次組合回測的報酬率雜訊很大，**訊號層的平均 R** 可靠得多。

### 一鍵對照實驗

```bash
python research_compare.py                    # baseline：原始 / 實盤真實 / 隨機進場
python research_compare.py --suite entry      # 進場方式拆解：FVG / 突破20日新高 / 季線上隨機 / 任意日隨機
python research_compare.py --sectors 半導體業 --seeds 20
```

只用研究期資料，結果存在 `research_results/`。

## 七、如果要實盤（研究完成之後）

> 目前研究結論是 FVG 進場沒有優勢，**建議暫停實盤**。以下流程留給未來找到有效進場方式之後使用。
> 系統目前**沒有**自動持倉監控和自動出場通知，以下步驟都要手動執行。

### 進場

1. 看 Tab 1 掃描結果
2. 系統會檢查市場環境，不在允許清單內就不給建議
3. 在券商掛**觸價單**，價格用系統給的「進場價」（這和實盤真實模式的回測方式一致）
4. 如果使用保護期，進場當天掛一張緊急停損單：
   - 停損距離 = 進場價 − 防彈止損價
   - 緊急停損價 = 進場價 − 停損距離 × 2
5. 自己記錄這筆交易（進場價、停損價、股數）

### 保護期內（前 10 個交易日）

- 只有緊急停損，正常波動不理會

### 保護期結束

- 取消緊急停損單，改掛正常停損單，價格用「防彈止損價」

### 持有期間與出場

- 每天收盤後手動更新最高價，移動停利線 = 最高價 − 停損距離 × 倍數
- 收盤跌破移動停利線 → 隔天開盤賣出

## 八、新手最常犯的錯

1. **相信舊版回測的報酬率**：那個數字建立在實盤做不到的成交假設上
2. **在研究期以外調參數**：看過考試期再改參數，考試期就失效了
3. **只看一次組合回測就下結論**：雜訊很大，要看訊號層平均 R 和隨機對照組
4. **回測和實盤用不同的設定**：單筆風險、進場方式、保護期都要一致
5. **單筆風險設太高**：風險 1.5% 加上 3% 停損，等於每筆部位佔帳戶 50%

## 九、心理準備

這類「小停損、讓利潤奔跑」的策略，最難的是心理：連續好幾個月小虧，然後某一筆突然賺 10 倍 R 把全部補回來。

但在那之前，更重要的是**確認策略真的有優勢**。紀律只能幫你執行一個有優勢的策略，不能把沒有優勢的策略變成有。

## 十一、已知問題

- **Tab 2 的 WFO 盲測按鈕會出錯**：`app.py` 預期 `run_backtest_core` 回傳 6 個值，實際只回傳 2 個
- **股票清單只有上市（.TW）**，沒有上櫃（.TWO）
- **股票清單只有現存公司**，有倖存者偏差
- **組合回測的最大回撤只用已實現損益計算**，持倉中的浮虧沒算進去，會低估回撤
