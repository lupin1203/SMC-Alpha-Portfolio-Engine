## ⚠️ 先讀這段：研究結論（2026-11-12）

**結論：這套策略不建議實盤。在研究期內，它贏不了「隨機挑日子進場」，也贏不了「直接買進持有 0050」。**

研究期 2014 年底到 2023 年底、全台股約 1030 檔，一律用實盤真實模式（實盤真的做得到的成交方式）：

| 設定 | 年化報酬 | 總報酬 | 最大回撤（含浮虧） |
|---|---|---|---|
| 原策略（FVG + 季線，5 檔、單筆風險 1.5%） | −0.7% | −6% | 37% |
| 目前最好的版本：FVG 無季線 + 排除爆量，分散持有 30 檔、單筆風險 0.2%（隨機排序 5 組平均） | 9.3% | +125% | 29% |
| 同樣 30 檔分散，但**進場日期隨機**（5 組平均） | **10.0%** | **+140%** | 32% |
| **買進持有 0050** | **11.7%** | **+175%** | 34% |

這代表：

1. 舊版回測的高報酬（+263%、+1600%）來自**實盤做不到的成交假設**。
2. FVG 訊號在「每個訊號單獨算」時比隨機進場好一點（平均 1.36R 對 1.13R），但**放進帳戶之後就不見了**。分散到 30 檔後，FVG 組合（+125%）反而輸給隨機進場的組合（+140%）。
3. 真正讓帳戶賺錢的是**出場規則（小停損、讓利潤奔跑）加上這幾年台股的多頭**，不是進場訊號。而單純買 0050 就能拿到這段多頭，而且回撤差不多。
4. 因為研究期就已經輸給 0050，**沒有必要動用考試期（2024 年以後）驗證**。考試期保留不用，將來如果有全新的策略想法，還能拿來做一次乾淨的驗證。

各次實驗的完整數字在 `research_results/` 資料夾，解讀在[第十節](#十目前研究進度)。

## 一、這套系統在做什麼

這是一個台股的量化交易系統，原始設計邏輯是：

1. **在選定的產業裡找出 FVG（Fair Value Gap）突破訊號的股票**
2. **用 0050 判斷大盤環境，只在允許的環境進場**
3. **進場後讓利潤奔跑，靠少數大波段賺錢**

它的性格：**勝率只有約 15–25%，大部分交易小虧，靠少數幾筆大波段把整體拉成正報酬。**

### 實際的交易規則（程式碼裡真正在做的事）

| 項目 | 規則 |
|---|---|
| 訊號 | 三根 K 線：第 3 根最低價 > 第 1 根最高價（缺口 ≥ 門檻），第 2 根是紅K，收盤在季線上，開盤跳空不超過 5% |
| 停損距離 | max(缺口大小, 收盤價 × 3%)。實務上幾乎都是 **3%** |
| 移動停利 | 最高價 − 停損距離 × 倍數。倍數 10 ≈ **從最高點回落 30% 才出場** |
| 市場環境 | 0050 vs 200 日均線（Bull / Bear）＋ 20 日年化波動率 25%（HighVol / LowVol） |

> 注意：雖然名稱叫 SMC，但它是在缺口形成當天**追價進場**，不是等回測缺口才進場。本質上比較接近「動能突破策略」。

## 二、第一次安裝（只做一次）

### 步驟 1：安裝 Python 套件

```bash
pip install -r requirements.txt
```

### 步驟 2：設定環境變數（Telegram 通知用，可略過）

**不要把金鑰寫在程式碼裡。**

```bash
export TELEGRAM_BOT_TOKEN="你的token"
export TELEGRAM_CHAT_ID="你的chat_id"
```

Windows 用「系統 → 環境變數」設定，或在 PowerShell 用 `$env:TELEGRAM_BOT_TOKEN="..."`。
沒設定也能用，只是不會發 Telegram 通知。

- **Telegram token：**在 Telegram 找 @BotFather 建立機器人取得。
- **chat_id：**找 @userinfobot 取得。

### 步驟 3：產生股票清單

```bash
python get_data.py
```

會從證交所抓上市公司清單，產生 `stock_list.csv`（欄位：`category,ticker,name`）。

### 步驟 4：下載歷史 K 線（第一次最久）

```bash
python update_data.py
```

約 1000 多檔，需要 30–60 分鐘。資料存在 `local_data/`（例如 `local_data/2330.parquet`）。
沒有先下載也可以用，系統會在需要時自動從 yfinance 抓，只是比較慢。

### 步驟 5：啟動系統

```bash
streamlit run app.py
```

瀏覽器會自動開啟 `http://localhost:8501`，看到五個分頁就成功了。

## 四、參數說明

舊版手冊的「最佳參數」是用舊的回測方式選出來的，**現在不建議直接當成定案**。以下只是目前的預設值：

| 參數 | 預設值 | 說明 |
|------|-----|------|
| 最小缺口 (gap) | 0.3% | FVG 缺口門檻 |
| 出場方式 | 移動停利，倍數 10 | ≈ 從最高點回落 30% 出場 |
| 單筆風險 | 0.5%（實盤雷達）/ 2%（回測預設） | 每筆最多虧帳戶幾 %。回測和實盤請設成同一個值 |
| 允許進場環境 | Bull_LowVol + Bear_HighVol | ⚠️ 這個組合是看歷史結果挑的，有過度擬合疑慮 |
| 最大持倉數 | 5 | 同時最多持有幾檔 |
| 單一產業上限 | 2 | 同產業最多幾檔 |

**關於舊版的「報酬率 1600%、最大回撤 22%」：**那是全期間、原始回測方式算出來的。它用訊號當天收盤價成交、漲停也買得到、只用已實現損益算回撤，而且股票清單沒有已下市公司。這個數字**不代表實盤能做到的績效**。

## 五、回測真實度：原始回測 vs 實盤真實模式

在 Tab 3 的「研究設定」勾選「實盤真實模式」，回測會改成模擬實盤真的做得到的事：

| 項目 | 原始回測 | 實盤真實模式 |
|---|---|---|
| 進場 | 訊號當天收盤價 | 隔天掛觸價單（觸價 = 訊號日收盤），有觸發才成交，成交價 = max(開盤, 觸價) |
| 漲停 | 照樣買到 | 一字漲停買不到 |
| 跌停 | 照樣賣掉 | 一字跌停賣不掉，留到隔天 |
| 前 10 天 | 1R 停損 | 只有 2R 緊急停損（天數可調，0 = 關閉） |
| 同一檔 | 可重複開倉 | 已有部位就略過新訊號 |
| 移動停利 | 同根 K 棒先上調再判斷 | 先判斷出場，收盤後才更新 |
| 資料結束時的未平倉部位 | 直接消失 | 以最後收盤價結算 |
| 單筆資金上限 | 無 | 預設 20% 淨值 |

不勾選時，結果和舊版完全相同。**研究時請一律用實盤真實模式。**

## 六、研究紀律（調參數之前必讀）

### 考試期（Holdout）

`config.py` 的 `HOLDOUT_START`（預設 2024-01-01）之後的資料保留當「最後考試」。

- Tab 3 預設只用**研究期**（之前的資料）
- 所有參數調整都只看研究期
- 全部定案後，才切到「考試期」驗證**一次**。看過考試結果再改參數，這段資料就失效了

### 隨機進場對照組

訊號數量不變，但進場日期隨機打散，出場規則完全不變。
**任何進場方式都要先贏過隨機對照組，才算真的有優勢。**

### 一次只改一個東西

每次只改一項規則，跟基準比較，只保留真的有改善的。並且記錄每一組試過的參數。

### 看訊號層，不要只看組合報酬

同樣是隨機進場，換一組亂數，組合報酬就從 +6% 跳到 +266%。單次組合回測的報酬率雜訊很大，**訊號層的平均 R** 可靠得多。

### 一鍵對照實驗

```bash
python research_compare.py                    # baseline：原始 / 實盤真實 / 隨機進場
python research_compare.py --suite entry      # 進場方式拆解：FVG / 突破20日新高 / 季線上隨機 / 任意日隨機
python research_compare.py --sectors 半導體業 --seeds 20
```

只用研究期資料，結果存在 `research_results/`。

## 七、如果要實盤（研究完成之後）

> 目前研究結論是 FVG 進場沒有優勢，**建議暫停實盤**。以下流程留給未來找到有效進場方式之後使用。
> 系統目前**沒有**自動持倉監控和自動出場通知，以下步驟都要手動執行。

### 進場

1. 看 Tab 1 掃描結果
2. 系統會檢查市場環境，不在允許清單內就不給建議
3. 在券商掛**觸價單**，價格用系統給的「進場價」（這和實盤真實模式的回測方式一致）
4. 如果使用保護期，進場當天掛一張緊急停損單：
   - 停損距離 = 進場價 − 防彈止損價
   - 緊急停損價 = 進場價 − 停損距離 × 2
5. 自己記錄這筆交易（進場價、停損價、股數）

### 保護期內（前 10 個交易日）

- 只有緊急停損，正常波動不理會

### 保護期結束

- 取消緊急停損單，改掛正常停損單，價格用「防彈止損價」

### 持有期間與出場

- 每天收盤後手動更新最高價，移動停利線 = 最高價 − 停損距離 × 倍數
- 收盤跌破移動停利線 → 隔天開盤賣出

## 八、新手最常犯的錯

1. **相信舊版回測的報酬率**：那個數字建立在實盤做不到的成交假設上
2. **在研究期以外調參數**：看過考試期再改參數，考試期就失效了
3. **只看一次組合回測就下結論**：雜訊很大，要看訊號層平均 R 和隨機對照組
4. **回測和實盤用不同的設定**：單筆風險、進場方式、保護期都要一致
5. **單筆風險設太高**：風險 1.5% 加上 3% 停損，等於每筆部位佔帳戶 50%

## 九、心理準備

這類「小停損、讓利潤奔跑」的策略，最難的是心理：連續好幾個月小虧，然後某一筆突然賺 10 倍 R 把全部補回來。

但在那之前，更重要的是**確認策略真的有優勢**。紀律只能幫你執行一個有優勢的策略，不能把沒有優勢的策略變成有。

### 進場方式拆解（研究期、實盤真實模式）

全台股 1030 檔，2014 年底到 2023 年底，出場規則全部相同（3% 停損、30% 移動停利），隨機對照組各跑 10 組。

| 進場方式 | 訊號平均 R | 組合總報酬 |
|---|---|---|
| 隨機進場（任意日） | **1.16** ± 0.02 | +112%（10 組平均） |
| FVG + 季線（原策略） | 1.06 | −20% |
| 隨機進場（只在季線上） | 1.00 ± 0.02 | +56%（10 組平均） |
| 突破 20 日新高 + 季線 | 0.95 | −5% |

**解讀：**

1. **季線濾網在扣分。**同樣是隨機進場，限定在季線上平均 R 從 1.16 掉到 1.00。在這套出場規則下，買已經漲上去的股票比較差。
2. **FVG 本身有一點點貢獻。**跟「只在季線上隨機進場」比，FVG 高了約 0.06R，大約是隨機組標準差的 3 倍，所以不是運氣。但這點貢獻抵不過季線濾網造成的損失。
3. **單純突破策略更差。**突破 20 日新高連「季線上隨機進場」都輸，追強勢股在這段期間不划算。
4. **下一步：**測「FVG 不加季線濾網」，以及「FVG 加上回檔條件」（例如等價格回到缺口才進場）。結果只能用研究期判斷。

### 季線濾網與回檔進場（研究期、實盤真實模式）

同樣條件：全台股 1030 檔，出場規則不變，隨機對照組各 10 組。

| 進場方式 | 訊號平均 R | 組合總報酬 |
|---|---|---|
| **FVG 無季線，追價** | **1.28** | −4% |
| FVG 無季線，回檔進場 | 1.17 | +97% |
| 隨機進場，追價 | 1.16 ± 0.02 | +112%（10 組平均） |
| FVG + 季線，追價（原策略） | 1.06 | −20% |
| FVG + 季線，回檔進場 | 1.06 | +63% |
| 隨機進場，回檔到當天低點 | 1.00 ± 0.03 | +122%（10 組平均） |

> 「回檔進場」= 出現 FVG 後，在缺口上緣（訊號日最低價）掛限價買單，5 天內有效。

**解讀：**

1. **拿掉季線濾網後，FVG 第一次明顯贏過隨機進場。**平均 R 1.28 比 1.16，差距大約是隨機組標準差的 5 倍。這是目前第一個有證據的進場優勢。
2. **回檔進場沒有幫助。**FVG 無季線時，回檔進場（1.17）比追價（1.28）差。原因可能是強勢的缺口通常不會回頭，等回檔反而錯過最好的那幾筆。
3. **但組合層還是不行。**訊號層最好的「FVG 無季線，追價」，組合報酬只有 −4%，最大回撤 38%，還輸給隨機進場的組合。訊號本身有優勢，但**組合層的選股和資金分配把優勢吃掉了**。可能的原因：
   - 用「成交量爆量倍數」排序挑股票，可能挑到比較差的訊號
   - 市場環境過濾（Bull_LowVol + Bear_HighVol）是看歷史挑的，可能在扣分
   - 單筆風險 1.5% 加上 3% 停損，每筆部位約佔 50% 帳戶，資金只夠買 2 檔，結果高度集中、雜訊很大
4. **要注意多重檢定。**到目前為止已經試了 6 種進場方式，挑出最好的那一種，本身就會有一點樂觀偏差。所以最後一定要用考試期驗證。

**下一步：**研究組合層。進場固定用「FVG 無季線，追價」，一次只改一項：排序方式、市場環境過濾、單筆風險。

### 組合層研究（研究期、FVG 無季線追價、實盤真實模式）

#### 1. 爆量倍數：越爆量越差（10 年都成立）

| 爆量倍數五分位 | 爆量倍數範圍 | 訊號數 | 平均 R |
|---|---|---|---|
| Q1 最低 | 0 – 0.53 | 4,897 | 1.42 |
| Q2 | 0.53 – 0.80 | 4,897 | 1.52 |
| Q3 | 0.80 – 1.16 | 4,896 | 1.83 |
| Q4 | 1.16 – 1.89 | 4,897 | 1.33 |
| **Q5 最高** | **1.89 以上** | 4,897 | **0.46** |

**爆量最大的那 20% 訊號明顯最差**，而且 2014–2023 **每一年**都比其他訊號差。但組合回測原本是「爆量倍數最高的優先買」，等於專挑最差的訊號。

組合回測也印證了這點：

| 排序方式 | 組合總報酬 | 最大回撤 |
|---|---|---|
| 爆量倍數高優先（原設定） | −4% | 38% |
| 隨機排序（10 組） | +38%（−18% 到 +78%） | 35% |
| **爆量倍數低優先** | **+92%** | 32% |

爆量倍數低優先的報酬（+92%）超出隨機排序的最好結果（+78%），不像是運氣。

#### 2. 市場環境：效果很大，但集中在少數幾次崩盤

| 環境 | 訊號數 | 平均 R | 出現年份 |
|---|---|---|---|
| Bear_HighVol（崩盤後） | 3,220 | **6.40** | 2015、2018、2020、2022，每次都是正的 |
| Bull_HighVol | 1,102 | 3.01 | 主要在 2021 |
| Bear_LowVol | 4,912 | 0.72 | |
| **Bull_LowVol（最常見）** | **12,646** | **0.24** | 9 年中有 5 年是負的 |

看起來「崩盤後買 FVG」非常好，但 Bear_HighVol 的總獲利有**約 89% 來自 2020 年 3–4 月和 2022 年 10–11 月**這兩次事件。真正獨立的樣本只有 4 次崩盤，太少了，不能用來精細調整過濾規則。

組合回測中改環境過濾的結果也都落在隨機排序的雜訊範圍內：不過濾 −2%，只做 Bull +30%。

**結論：**不要再根據這張表挑環境組合，那會重蹈當初四格挑兩格的覆轍。

#### 3. 單筆風險 0.5%

報酬差不多（−6%），最大回撤從 38% 降到 26%。比較分散，也比較接近實盤設定。

#### 這次的重點

1. **爆量過濾是目前最可靠的發現。**它在每一年都成立，有經濟上的解釋（爆量長紅常常是短線過熱、追高的人最多的時候），也被組合回測印證。
2. **市場環境過濾要保持簡單。**「崩盤後的反彈訊號特別好」有道理，但樣本只有 4 次，現階段不適合拿來調參數。
3. **組合回測的雜訊非常大。**光是換排序的亂數，報酬就從 −18% 跳到 +78%。判斷優劣要以訊號層為主。

**下一步：**把「排除爆量倍數最高 20%（約 > 1.9 倍）」或「爆量倍數低優先」正式加進策略，並決定一個簡單的環境規則（例如不過濾）。然後補上倖存者偏差、逐日盯市回撤這兩項修正，最後用考試期驗證一次。

### 爆量過濾實驗（研究期、實盤真實模式，2026-11-11）

`python research_compare.py --suite volfilter`，全台股 1034 檔，2014-11 到 2023 年底。
「排除爆量」= 訊號日成交量 ÷ 20 日均量 > 1.9 的訊號不進場。詳細數字在 `research_results/compare_volfilter_20261111_2122.md`。

**訊號層**

| 進場方式 | 訊號數 | 平均 R |
|---|---|---|
| A. FVG + 季線（原策略） | 20,094 | 1.06 |
| B. A + 排除爆量 | 17,788 | 1.18 |
| C. FVG 無季線 | 25,417 | 1.28 |
| **D. C + 排除爆量** | 24,011 | **1.36** |
| 隨機進場（10 組） | 27,372 | 1.13 ± 0.03 |

**組合層**（最多 5 檔、單筆風險 1.5%）

| 設定 | 總報酬 | 逐日盯市最大回撤 |
|---|---|---|
| A. FVG + 季線（原策略） | −6% | 37% |
| B. A + 排除爆量 | +21% | 42% |
| C. FVG 無季線 | +18% | 46% |
| D. C + 排除爆量 | −4% | 41% |
| D + 爆量倍數低優先 | +123% | 43% |
| D + 隨機排序（10 組） | +39%（−3% 到 +142%） | 43% |
| D + 單筆風險 0.5% | −8% | 31% |
| 隨機進場（10 組） | +89%（+16% 到 +183%） | 37% |
| **同期間買進持有 0050** | **+175%** | **34%** |

**解讀：**

1. **訊號層：爆量過濾有小幅、但穩定的改善。**無季線時 1.28 → 1.36，而且 2014–2023 每一年都是過濾後比較好。D 比隨機進場高約 0.23R，是隨機組標準差的 8 倍左右。
2. **組合層：還是沒有變成帳戶報酬。**D 的組合報酬是 −4%；「爆量低優先」的 +123% 落在隨機排序的範圍（−3% 到 +142%）內，不能排除只是運氣。
3. **所有組合都輸給買進持有 0050（+175%），回撤還比較大。**這是目前最重要的一個數字。
4. **問題出在組合層，不是進場條件。**24,000 個訊號裡組合只買了約 170–230 筆（不到 1%），而這個策略勝率只有 15–20%、R 的中位數是 −1.4，獲利全靠少數大贏家。只抽 1% 的話，有沒有抽到大贏家幾乎是運氣。
5. **注意樂觀偏差：**1.9 這個門檻是看研究期資料挑的，到這裡也已經試過十幾種設定。

**下一步：**讓組合更接近訊號層的平均（分散持有），並和買進持有 0050 比較。結果見下一段。

### 分散持有實驗（研究期、實盤真實模式，2026-11-12）

`python research_compare.py --suite diversify --seeds 5`，進場固定為「FVG 無季線 + 排除爆量」，只改組合層。
詳細數字在 `research_results/compare_diversify_20261112_0044.md`。研究期約 9.2 年。

| 組合設定 | 交易次數 | 總報酬 | 年化 | 最大回撤（含浮虧） |
|---|---|---|---|---|
| 5 檔、風險 1.5%（原設定） | 173 | −4% | −0.4% | 41% |
| 10 檔、風險 0.5% | 353 | +21% | 2.1% | 36% |
| 20 檔、風險 0.3% | 645 | +25% | 2.5% | 31% |
| 30 檔、風險 0.2% | 949 | +39% | 3.7% | 31% |
| 30 檔、風險 0.2%、不過濾市場環境 | 1,421 | −15% | −1.7% | 28% |
| 20 檔，隨機排序（5 組） | 662 | +115%（+46% 到 +194%） | 8.7% | 30% |
| 30 檔，隨機排序（5 組） | 993 | +125%（+96% 到 +158%） | 9.3% | 29% |
| **30 檔，隨機進場**（5 組） | 1,079 | **+140%**（+56% 到 +278%） | **10.0%** | 32% |
| **買進持有 0050** | — | **+175%** | **11.7%** | 34% |

**解讀：**

1. **分散確實讓結果變穩定**：持倉從 5 檔增加到 30 檔，回撤從 41% 降到 29–31%，隨機排序的報酬範圍也從「−3% 到 +142%」縮小到「+96% 到 +158%」。
2. **預設的「爆量倍數高優先」排序很傷**：同樣 30 檔，用預設排序只有 +39%，隨機排序平均 +125%。這和之前「爆量越大的訊號越差」的發現一致；排序本身就在專挑比較差的訊號。
3. **但就算排除排序的影響，FVG 還是輸給隨機進場**（+125% 對 +140%），兩者都輸給 0050（+175%）。訊號層那 0.2R 的優勢，在組合層完全看不到。
4. **市場環境過濾在這裡有幫助**（不過濾 −15%，過濾 +39%），但之前已經發現這個效果集中在 2020、2022 兩次崩盤，樣本太少，不能當成可靠的優勢。

**結論：**沒有任何一個版本贏過買進持有 0050，所以**不建議實盤，也不動用考試期**。這套程式保留作為回測工具；之後如果要再研究，應該換一個全新的進場或出場想法，而不是繼續在 FVG 上調參數。

## 十一、已知問題

- **股票清單只有上市（.TW）**，沒有上櫃（.TWO）。`data_provider` 已經認得 `.TWO` 代號，但 `get_data.py` 還不會抓上櫃清單
- **股票清單只有現存公司**，有倖存者偏差
- **`min_vol`（最低成交量）參數沒有作用**：回測引擎收了這個參數但沒有拿來過濾。現有的研究結果都是在「沒有成交量過濾」下跑出來的，所以先不改，避免舊數字對不起來；要加的話請當成一項新實驗
- **本機 K 線快取不會自動更新**：`local_data/` 有檔案就直接用。掃描雷達會檢查資料日期，超過 4 天會擋下來，請先跑 `python update_data.py`
- **`research_results/` 裡的最大回撤是舊算法**（只看已實現損益）。新的「逐日盯市最大回撤」會比較大，重跑 `research_compare.py` 才會更新

### 2026-11 修掉的問題

- Tab 2 回測按鈕會當掉（預期 6 個回傳值，實際 2 個），而且滑價被放大 100 倍（介面填 0.1% 卻當成 10%）
- `walk_forward.py`、`wfa_optimizer.py` 無法執行，且用了 10% 的滑價和交易稅；現在共用 `summarize_trades`，成本和主引擎一致
- `research_pipeline.py` 的濾網參數名寫錯，策略會靜靜忽略，消融實驗每一列結果都一樣
- 掃描雷達的進場價用的是「當天最低價」，和回測（訊號日收盤觸價）不一致
- Tab 5 熱力圖用全期間資料挑參數，等於偷看考試期；現在只用研究期
- 組合回測的最大回撤只算已實現損益；新增逐日盯市回撤
- `run_backtest_core` 會擋掉 ≥ 5% 的滑價（幾乎一定是把百分比當成比例傳）
