# SMC 量化交易系統 — 新手使用手冊

> 給第一次使用這套系統的人。照著做就能跑起來。

---

## 一、這套系統在做什麼

這是一個台股的量化交易系統，核心邏輯是：

1. **用月營收和股價動能找出最強的產業**（雷達）
2. **在這些產業裡找符合 SMC（Smart Money Concept）進場點的股票**
3. **進場後讓利潤奔跑，靠少數大波段賺錢**

它的性格你要先知道：**勝率只有約 25%，但賺的時候賺很大。** 大部分交易是小虧，靠少數幾筆大波段把整體拉成正報酬。這代表你要能忍受連續幾個月平淡甚至小虧，等待大行情。

## 二、第一次安裝（只做一次）

### 步驟 1：安裝 Python 套件

打開終端機，切換到專案資料夾，執行：

```bash
pip install -r requirements.txt
```

### 步驟 2：設定環境變數

系統需要兩組金鑰，**不要寫在程式碼裡**，要設成環境變數：

```bash
# Telegram 機器人（接收每日通知用）
export TELEGRAM_BOT_TOKEN="你的token"
export TELEGRAM_CHAT_ID="你的chat_id"

# FinMind（抓月營收和財報用）
export FINMIND_TOKEN="你的finmind_token"
```

Windows 在「系統 → 環境變數」裡設定，或用 PowerShell 的 `$env:` 指令。

**Telegram token 怎麼拿：** 在 Telegram 找 @BotFather 建立機器人，會給你 token。chat_id 找 @userinfobot 取得。

**FinMind token 怎麼拿：** 到 finmindtrade.com 註冊免費帳號，在會員中心取得 API token。

### 步驟 3：建立股票清單

在專案資料夾建立 `stock_list.csv`，三個欄位：

```
ticker,name,category
2330.TW,台積電,半導體業
2317.TW,鴻海,電子零組件業
...
```

### 步驟 4：下載歷史資料（很重要，第一次最久）

```bash
# 先建立 K 線資料庫
python nuclear_update.py

# 再下載月營收和財報歷史（Step 3 會跑很久，2500 檔約 1-2 小時）
python update_data.py
```

這一步完成後，`local_data/`（K 線）、`revenue_cache/history/`（月營收）、`revenue_cache/margin_history/`（毛利率）三個資料夾才會有資料。

### 步驟 5：啟動系統

```bash
streamlit run app.py
```

瀏覽器自動開啟 `http://localhost:8501`，看到七個分頁就成功了。

## 三、七個分頁各做什麼

| 分頁 | 用途 | 你會用到的頻率 |
|------|------|--------------|
| **1. 即時掃描雷達** | 找今天可以進場的股票 | 每天 |
| **2. 深度回測實驗室** | 測單一股票的歷史表現 | 偶爾 |
| **3. 投資組合回測** | 測整個策略的歷史績效 | 調參數時 |
| **4. 歷史戰績資料庫** | 看過去的回測記錄 | 偶爾 |
| **5. 防禦與衰減檢定** | WFO 盲測、Alpha 衰減、出場分析 | 重大調整後 |
| **6. 實盤對帳** | 記錄真實交易，比對滑價 | 每次交易 |
| **7. 參數變更日誌** | 記錄你改了什麼參數 | 每次調參數 |

## 四、目前驗證過的最佳參數

這些是經過大量測試後的設定，新手直接用這組就好：

| 參數 | 值 | 說明 |
|------|-----|------|
| 最小缺口 (gap) | 0.3% | FVG 缺口門檻 |
| 移動停利 | 10% | 獲利目標追蹤距離 |
| 單筆風險 | 0.5%（實盤）/ 1.5%（回測） | 每筆最多虧帳戶幾 % |
| 允許進場環境 | Bull_LowVol + Bear_HighVol | 只在正期望值環境進場 |
| 最短持倉天數 | 10 天 | 進場後 10 天保護期 |
| 最大持倉數 | 5 | 同時最多持有幾檔 |
| 單一產業上限 | 2 | 同產業最多幾檔 |

**回測績效參考（2015-2026 全台股）：**
報酬率約 1600%、最大回撤 22%、夏普比率 1.06、勝率 25%。

**但要知道：** WFO 盲測穩定性只有 37.5%，代表這個績效在不同年份差異很大，不是每年都賺。

## 五、實盤操作流程（最重要）

### 進場時

1. 早上看 Tab 1 掃描結果，或收 Telegram 通知
2. 確認當前市場環境是 `Bull_LowVol` 或 `Bear_HighVol`（不是就空手）
3. 在券商掛**進場觸價單**，價格用系統給的「進場價」
4. **進場當天掛一個緊急停損單**，價格設在「進場價 − 2 倍停損距離」
   - 停損距離 = 進場價 − 防彈止損價
   - 緊急停損價 = 進場價 − (停損距離 × 2)
5. 在 Tab 6 記錄這筆交易（進場價、停損價、股數）

### 保護期內（前 10 個交易日）

- **不要動**。這段時間只有緊急停損會觸發，正常波動不理會。
- 系統每天會監控，跌超過 2 倍停損距離才會發緊急通知。

### 保護期結束（第 11 天）

- 系統發 Telegram 提醒「保護期結束」
- 去券商把緊急停損單**取消**，改掛正常停損單，價格用「防彈止損價」

### 持有期間

- 系統每天收盤後追蹤最高價，更新移動停利線
- 收盤跌破移動停利線 → 系統發通知「建議明日開盤賣出」
- 每月 10 號系統檢查基本面，月營收轉負或毛利衰退會發警告
- 每週五系統發持倉週報

### 出場時

1. 收到出場通知後，明日開盤賣出
2. 在 Tab 6 確認出場，記錄實際成交價

## 六、每日流程表

### 平日（週一到週五）

| 時間 | 動作 | 誰做 |
|------|------|------|
| 08:45（開盤前） | 看昨晚美股、今日有無持倉要注意 | 你 |
| 09:00（開盤） | 執行昨天決定的進出場掛單 | 你 |
| 13:30（收盤） | — | — |
| 14:45（收盤後） | 系統自動跑：更新資料 → 持倉監控 → 掃描 → 發 Telegram | 系統 |
| 晚上 | 看 Telegram 通知，決定明天要不要進出場 | 你 |

### 自動排程設定（Linux/Mac cron）

```bash
# 編輯排程
crontab -e

# 加入這行（每個交易日 14:45 跑）
45 14 * * 1-5 cd /你的專案路徑 && python daily_scheduler.py
```

Windows 用「工作排程器」設定每天 14:45 執行 `python daily_scheduler.py`。

### 每月一次

- 10 號左右系統會自動跑基本面檢查（月營收公布後）
- 你只要看通知就好

### 每季一次

- 重新檢視 Tab 5 的 WFO 和 Alpha 衰減，確認策略還有效
- 如果調了參數，到 Tab 7 記錄下來

## 七、新手最常犯的錯

1. **沒等保護期就停損** — 前 10 天的正常波動不要理，這是策略設計的一部分
2. **在 Bull_HighVol 環境進場** — 這個環境期望值是負的，系統會擋，但你手動進場就破功了
3. **看到連續小虧就放棄** — 這套系統本來就是大部分時間小虧，要等大波段
4. **單筆風險設太高** — 實盤先用 0.5%，跑順了再考慮加
5. **沒記錄實盤交易** — Tab 6 一定要記，不然你不知道真實滑價和回測差多少

## 八、心理準備

這套系統最難的不是技術，是心理。

它會讓你連續好幾個月小虧，然後某一筆交易突然賺 10 倍 R 把全部補回來。如果你在那筆大的來之前就放棄，就前功盡棄。

前 5 筆大交易貢獻了將近一半的利潤。你不知道下一筆大的什麼時候來、是哪一檔。你能做的就是嚴格執行紀律，讓系統有機會抓到那幾筆。

**先用小錢跑三個月，確認你能承受這個性格，再決定要不要加碼。**
